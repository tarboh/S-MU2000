# サンプリングして、MIDI の音源として鳴らすまで

MU2000 は**外から入れた音を録って、その音を MIDI の音色として鳴らせる**。ここでは
A/D INPUT に音を入れるところから、シーケンサや DAW から鳴らすところまでを順に書く。

この文書の手順は、**エミュレータの firmware を実際に動かして確かめたもの**（画面の文字は
そのまま写した）。確かめていないところは、そう書いてある。

| | |
|---|---|
| サンプリング RAM | 標準で **4096KB**（`SAMPLING` → `RAM` で `USED` と `FREE` が見られる）。録れる長さは 48 秒ほど |
| 録り方 | 44100Hz・16bit。入口は A/D INPUT の 1（左）と 2（右） |
| 電源を切ると | **消える**。残すなら SmartMedia へ保存する（下の 6.） |
| DAW では | プロジェクトに残る（機械まるごとの状態に入る。下の 7.） |

## 1. 音の入口を用意する

| 使い方 | やること |
|---|---|
| `gui.exe` | パネルの **`A/D INPUT` のジャックを左クリック**（窓のどこかを右クリックでもよい）して、録音デバイスを選ぶ。左が AD1、右が AD2。44100Hz でなければ中で直す |
| VST3・CLAP・AU | 補助の音声入力バス **`A/D Input`**（ステレオ）に繋ぐ。DAW ではサイドチェーンの入力として見えることが多い。左が AD1、右が AD2 |

**入れた音をそのまま聞きたいときは、A/D パートの音量を上げる。** 初期値は 0 なので、
何も聞こえないのが正しい。XG のパラメータチェンジで上げる（AD1 が `10 00 0B`、AD2 が `10 01 0B`）。

```
F0 43 10 4C 10 00 0B 64 F7      AD1 の音量を 100 に
```

録音そのものは、この音量とは関係なく入る。

## 2. 録る（SAMPLING → REC）

パネルの **`SAMPLING`**（`gui.exe` のキーボードなら `M`）を押すと品書きが出る。

```
 EDIT  LOAD  SAVE
 REC   UTIL  RAM
```

`SELECT ◀ ▶` で **`REC`** に合わせて `ENTER`。

```
<REC>[         ]
 Sp=001     48s
```

`Sp=` が録り先の番号、その右が残りの時間。`SELECT ▶` で設定のページが変わる。

| ページ | 中身 |
|---|---|
| `Sp=001   48s` | 録り先の番号と、残りの秒数 |
| `TriggerLvl=off` | 音が入ったら録り始める引き金の高さ。`off` なら手で始める |
| `InputGain=line` | 入力の増幅（`line` / `mic`） |
| `InputSrc=AD1` | どの入口から録るか（`AD1` / `AD2` / `AD1+2`） |

`ENTER` を押すと録り始める。

```
<REC>[         ]
 Recording!  46s
```

もう一度 `ENTER` で止め、`EXIT` を押すと

```
 Keep Sample 001?
```

`ENTER` で残す（`EXIT` なら捨てる）。

## 3. 録れたものを見る・聞く（EDIT → SAMPLE）

`SAMPLING` → `EDIT` → `SAMPLE` → `ENTER`。

```
SMPL001 take001
 Name[]
```

`SELECT ▶` でページが変わる。

| ページ | 中身 |
|---|---|
| `Name[]` | 名前を付ける |
| `Start=0000000` | 鳴らし始める位置 |
| `End  =0089297` | 鳴らし終わる位置 |
| `Loop=off` | 繰り返し |
| `Trim` | いらないところを切る |

**`AUDITION` ボタン**（`gui.exe` のキーボードなら `Z`）を押すと、その場で試聴できる。

## 4. 音色にする（EDIT → VOICE）

録ったサンプルは、そのままでは MIDI から選べない。**音色（VOICE）に割り当てる**。

`SAMPLING` → `EDIT` → `VOICE` → `ENTER`。

```
PGM001:<NONE>
 Bank#=000
```

`SELECT ▶` で `Sp=` のページまで進み、`VALUE +` でサンプルを選ぶ。

```
PGM001:Voice001
 Sp=001 take001
```

これで音色 `PGM001` が `Voice001` になった。ほかのページは次のとおり。

| ページ | 中身 |
|---|---|
| `Bank#=000` | この音色を置くバンクの番号 |
| `Name[]` | 音色の名前 |
| `Sp=None` | **どのサンプルを鳴らすか**（ここで割り当てる） |
| `Level=***` | 音量 |
| `Pan=**` | 定位 |
| `Init` | まっさらに戻す |

## 5. MIDI から鳴らす

**バンクセレクト MSB を 16** にして、音色の番号をプログラムチェンジで送る。

| 送るもの | 値 |
|---|---|
| バンクセレクト MSB（CC0） | **16** |
| バンクセレクト LSB（CC32） | 0（`Bank#` で変えたならその番号） |
| プログラムチェンジ | 音色の番号 − 1（`PGM001` なら 0） |

```
B0 00 10   B0 20 00   C0 00      ch1 を Voice001 にする
```

LCD の音色の名前が `Voice001` に変わる。あとは普通に鍵盤を弾けば鳴る。

**ノート 60（中央のド）が、録ったときの高さ**。そこから半音ずつ上下する。
実際に 440Hz の音を録って確かめた結果が下（`--probe` で測った）。

| 弾いた鍵 | 出た高さ |
|---|---|
| 36 | 110.0 Hz |
| 48 | 220.0 Hz |
| 60 | **440.0 Hz**（原音） |
| 72 | 880.0 Hz |

## 6. SmartMedia に残す・読み戻す

サンプリング RAM は電源を切ると消える。残すならカードへ。

1. **カードを差す** … `gui.exe` ならパネル左下の差し込み口をクリックして
   「新しい SmartMedia を作って差す」（[gui.md](gui.md)）
2. **書式化** … `UTIL` → `CARD` → `Format` → `ENTER`。`Executing` が消えるまで待つ
3. **保存** … `SAMPLING` → `SAVE` → `ENTER` → `ALL+SEQ` → 保存先 → 名前（既定は `ALL_SEQ`）→ `ENTER`。
   `SAVING` が消えれば終わり
4. **読み戻し** … 別の機械（や次に起動したとき）で `SAMPLING` → `LOAD` → 同じファイルを選ぶ

`make test` の 7 番（`build/samptest.exe`）が、この保存と読み戻しを毎回確かめている。
読み戻しは、下の「窓から」のカードのタブと同じボタンの押し方（`src/ui/panel_macro.h`）で行い、
書いたカードを本体を通さずに読んで（`src/card_fs.h`・`src/m2a.h`）、波形が表のサンプルと同じ長さ・同じ音かも見る。
読み戻すカードは、取り出した M2A を PC の側で新しいカードに書き直したもの（`smartmedia::format` にファイルを渡す）で、
firmware がそれを読めることも同時に確かめている。

## 7. DAW ではどうなるか

プロジェクトを保存すると、**サンプルも音色の割り当ても一緒に残る**（プラグインは機械まるごとの
状態を保存するため。[automation.md](automation.md) の版 2）。開き直すと、そのまま
バンク MSB 16 で鳴らせる。

確かめ方は、録って割り当てた機械の状態を保存し、別の機械に戻して同じ MIDI を送るというもので、
出音は元の機械と同じだった（rms 0.0470、440Hz 成分 0.03323 でどちらも一致）。

**ただしプロジェクトが大きくなる。** サンプリング RAM の中身がそのまま状態に入るので、
何も録っていなければ 30 万バイトほどの状態が、4MB 録ると 6MB ほどになる（詰める前の大きさ）。

## 窓から（パネルを使わずに）

上の手順は全部パネルでやるが、PC の窓からもできる。gui の上の帯（またはプラグインの帯）の
**Sampling**（`--sampling-window` で起動と同時にも開く）。firmware の表を直に読み書きするので、
液晶の品書きを辿らなくてよい（表の形は [sampling-ram.md](sampling-ram.md)）。
窓は 2 列。左がサンプルの一覧（どの方法で用意したものもここに並ぶ）。右はタブが 2 つで、**音の用意** の中に手段ごとの子タブ（**録音・取り込み** / **カード** / **波形を作る**）、**音の加工** の中に **サンプル**（波形・トリム・ループ）と **音色**（要素ごとの割り当て・フィルター・LFO・EG）の子タブがある。

| 区画 | できること |
|---|---|
| 入力 | **音の用意** → **録音・取り込み** の左。録音デバイスを選ぶ（gui。プラグインはホストの A/D Input バス）。録る入力（AD1 / AD2 / AD1+2）、引き金（なし、または -60〜0 dB）、レベルメーター |
| 録音 | 同じタブの右。名前を付けて **録音** → **止める**。止めたときに firmware の表に足す。名前を空にすると firmware と同じ `take001` の形。**SysEx を読み込む** で、サンプリングの .syx（「まるごと SysEx に書き出す」で保存したものや、実機から読み出した一括ダンプ）を読み込む。波形とサンプルの表はメモリーに直に書くので、MIDI で送るときのような待ちは無い（実機の 13 秒ぶん・1.5MB の控えが数秒。頭で全部を消すファイルは、いまのサンプルとサンプル音色を置き換えるので先に確かめる）。**WAV を取り込む** で WAV ファイルからも足せる（録る入力で選んだチャンネルを 44.1kHz に直す。PCM 8/16/24/32bit と 32bit 浮動小数） |
| サンプル | 左の列。firmware の表にあるサンプルの一覧（パネルで録ったものも出る）。長さと最大の大きさ（無音なら「無音」）も出る。一覧の下の **まるごと SysEx に書き出す** / **まるごと MIDI で送る** で、波形・サンプル・それを鳴らす音色の全部を、MU2000 が MIDI で受け取る SysEx（機種 0x68 の一括ダンプ。[sampling-ram.md](sampling-ram.md)）にして .syx に保存する・送り先へ送る。**1 通目が受け取る側のサンプルとサンプル音色を消す**（置き換えになる）。波形 64 バイトが 85 バイトの 1 通になり、1 秒に 2800 バイトで送るので、波形 1 秒ぶんに 42 秒かかる（録った音より、作った波形のような短いもの向き）。送っている間は **やめる** で止められる |
| 波形 | **音の加工** → **サンプル**。一覧で選んだサンプルの波形（満杯で頭が切れた所は赤）。**ノーマライズ**（最大を -0.5 dB に）と、dB を決めて **音量を変える**（サンプルそのものを書き換えるので元に戻せない）。**始点 S**（緑。左クリック）と **終点 E**（黄。右クリック）で鳴らす所を決める（**前後の無音を除いて選ぶ** でも）。**ループ** を入れると、鍵盤を押しているあいだ **ループの頭 L**（紫。Shift を押しながらクリック）から E までをくり返す。S・E・L は波形を切らずに鳴らすための表へすぐ書く（firmware の EDIT → SAMPLE の Start・End・Loop と同じ欄。firmware の Loop は全体のくり返しだけだが、ここでは途中から回せる）。**トリム** は S より前と E より後ろを切り捨ててメモリを空ける（後ろのサンプルを前へ詰め、表の番地も書き直す。元に戻せない）。全体の波形の下に **始点・終点・ループの頭の拡大** を 3 つ並べる。それぞれ左クリック（ドラッグ）でその点を置き、ホイールで拡大・縮小、下のスクロールバーで表示を動かす（点が動くと表示はその点へ戻る）。ループが入っていれば、終点の枠には戻った後に鳴る L の後ろを、ループの頭の枠には戻る前に鳴る E の手前を薄く重ねる（つなぎ目の形が見える）。つなぎ目の道具: **ゼロクロスに吸い付ける**（マウスで置いた線を、10ms 以内で下から上へ 0 を横切る所へ寄せる）、**終点をループに合わせる**（E を 50ms 以内で、まわりの波形が L のまわりといちばん似ている所へ動かす）、**クロスフェード**（E の手前を L の手前と混ぜて書き換え、戻るときの段差を消す。元に戻せない。曲線は「形の似た音向け」（足して 1）と「揺れのある音向け」（等パワー。音程が揺れる音を長く混ぜても途中で痩せない）、**ループ区間を探す**（S〜E のあいだで、決めた長さ以上あり、つなぎ目のまわりの波形がいちばん似ている L と E の組を総当たりで探して置く。重いので波形を写して別の糸で探す）。生の音でループがプチプチ言うときは、0.3〜1 秒の落ち着いた所を探させ、揺れのある音向けで 100〜300ms のクロスフェードをかけるとよい |
| カード | **音の用意** → **カード**。SmartMedia の中身を、本体に読み込まずに見る。見るのは **差しているカード** か、**カードか M2A のファイル**（`開く…` で選んだ `.sm` / `.img` / `.m2a`）。`.m2a` を開くと、それを一番上に置いた新しいカード（入るいちばん小さい容量。名前は 8.3 の大文字に直し、日本語などの字は落とす）として見せ、差すか読み込むときに設定のフォルダの `cards` へ `.sm` として保存してから差す。左にファイルの一覧（下のディレクトリの中も）、`.M2A` を選ぶと右に中のサンプルの一覧（名前・長さ・ループの有無）が出る。サンプルを選ぶと波形（ループの頭は紫の線）が出て、**試聴** で PC からそのまま鳴らせる（音源を通さない。ループがあれば止めるまでくり返す）。**このカードを差す** で開いたファイルを差し込み口に差し（いま差しているカードは抜ける）、**この M2A を本体に読み込む** で前面パネルの `SAMPLING` → `LOAD` → `ALL+SEQ` を代わりに押してそのファイルを選ぶ（実機で押すのと同じ道なので firmware の LOAD がそのまま動く。押している間は音源を早送りするので、1 秒ほどで終わる。いまのサンプルとサンプル音色は置き換わる。「Overwrite ALL?」と聞かれたら ENTER で答える）。開いたファイルから読み込むときは、先に差してから読み込む。この方法で選べるのはカードのいちばん上にあるファイルだけ |
| 波形を作る | **音の用意** → **波形を作る**。録る代わりに、PC で作った 1 周期の形をサンプルにする（`src/wavegen.h`）。作り方は 17 個: **基本の波形**（サイン・ノコギリ・矩形（パルス幅つき）・三角）、**倍音を足す**（倍音 1〜32 の棒を上下に引く。「ランダム」で 1/√n の傾きにでたらめな強さ）、**手描き**（1 周期をなぞる。**段数** と **bit** を落とすと波形メモリ音源の階段になる。32 段・4bit がゲームボーイ、32 段・8bit が SCC）、**ノイズ**（白・ピンク・ブラウン）、**ファミコン**（2A03。矩形のデューティ 12.5・25・50・75%、4bit・32 段の階段の三角、シフトレジスタのノイズの長い周期と短い周期）、**FM**（2 オペレーター。キャリアとモジュレーターの比（整数）、変調の深さ、フィードバック。エレピ・ベル・ブラスなどの置き場つき）、**オルガン**（ドローバー 9 本、1 段 3dB。16' と 5⅓' があるのでループは 2 倍の長さ）、**ユニゾン**（同じ形を 2〜9 個、8.6 セント刻みでずらして重ねる。ノコギリならスーパーソー。うなりごと 0.76 秒のループに入る）、**声**（ノコギリに母音 あ・い・う・え・お のフォルマントをかける。あいだも選べる。「2 つ目の母音へ行って戻る」で、母音がうつり変わるうねりを 0.76 秒のループに焼き込む）、**シンク**（ハードシンク。従う側の速さ 1〜12 倍）、**フォールド**（サインを折り返す。量とかたより）。**PWM**（矩形の幅のうねりを 0.76 秒のループに焼き込む）、**プラック**（はじいた弦。Karplus-Strong）、**ドラム**（キック・スネア・タム・ハイハット・クラップ・カウベル。高さ・長さ・音色）、**PD**（位相ひずみ。カシオ CZ のやり方で、サインからノコギリ・矩形へ曲げる。レゾナンスの波形も）、**ベル**（減衰する FM。半端な比で金属の響き。チューブラー・グラス・ゴング・マリンバの置き場）、**絵で描く**（ANS シンセサイザーにならった、絵で描くループ。48 行 × 64 列の桝で、行がサイン 1 本（下が低い）、横がループの中の時間、濃さが大きさ。左ボタンで描き、右ボタンか Shift で消す。**行の間隔** が 1.00 なら行は倍音 1〜48、ほかの値なら倍音でない並び（鐘や金属の響き）。絵は 0.76 秒のループになり、右の端が左の端へつながるのでつなぎ目は出ない。ループの中でスペクトルが動く・明滅する音を 1 つの波形で作れる。高い鍵ほど速く回る）。プラック・ドラム・ベルは 1 度鳴って消える音で、ループを入れずに登録する（要素ごとに鍵の範囲を分ければキットが組める）。どれにも **ローファイ**（bit 数を減らす・同じ値を数サンプル続ける）をかけられる。どれもいったん倍音に直してから組み直すので、**倍音の上限** で丸めたり、高い鍵での折り返しを減らしたりできる。下に鳴る形（1 周期）と倍音の分布が出る。**再生** は PC でそのまま鳴らす（鍵 60 の高さ）。**サンプルとして登録** で、4214 サンプルに 25 周期ぶんの波形をサンプリング RAM に書いてループを入れる（261.63Hz ＝ 鍵 60 の C3 なので音程を直さなくてよい。使う容量は 0.1 秒ぶん）。チェックを入れておけば、割り当ての欄で選んでいる音色の要素 1 にも入る。登録したものは録ったサンプルと同じに扱えるので、ほかの要素に内蔵ウェーブや別の波形を重ねられる |
| 音色への割り当て | **音の加工** → **音色**。Bank# と番号で音色を選び、**要素 1〜4** のタブで要素ごとに（1 つの音色に 4 つまで重ねて鳴らせる。「この要素を鳴らす」で使う要素を決め、**鍵の範囲**・**強さの範囲**で鍵盤や強さで分けられる。実機でも 2 要素が鳴ることを確かめた）サンプル（サンプリング RAM のものか、**内蔵ウェーブ**。MU2000 の XG の音色が鳴らしている波形の組 0-502 を、その組を使う音色の名前つきで選べる。名前で絞り込める）・名前・音量・パン・音程・**エンベロープ**（アタック、ディケイ 1・2 とその行き先のレベル、リリース）を **書き込む**。左の列の下に、要素ごとの **フィルターと強さ**（カットオフ・レゾナンス・ハイパス・強さの曲線）、**LFO**（波形 ノコギリ / 三角 / S&H、スピード、ディレイ、フェーズイニシャライズ、音程・フィルター・音量への深さ）、**ピッチ EG**（デプスと、速さ 4 つ・レベル 5 つ）、**フィルター EG**（速さ 4 つ・レベル 5 つ）がある（MU Sampling Editor のボイスエディットにある項目。形の目安つき）。**押して試聴** は、押しているあいだ今の値を音色に書いてパート 1 をその音色にし、決めた鍵を音源で鳴らす（離すとノートオフ。音程・エンベロープ・ループが実際に効いた音で、リリースも聞ける）。**パート 1 で選ぶ** でパート 1 をその音色にして鳴らせる。**SysEx に書き出す** / **MIDI で送る** で、音色まるごとを実機の MU2000 も受け取る SysEx（機種 0x68 のパラメータチェンジ 334 通。[sampling-ram.md](sampling-ram.md)）にして .syx に保存する・送り先へ送る。書いた値は音色を選び直したときに効く |
| 内蔵ウェーブ | **内蔵ウェーブ**のタブ。MU2000 の内蔵の波形の組（W0〜W502）を一覧にして、選んだものを**波形だけで**鳴らし（フィルターもエンベロープも通さず、もとの鍵の高さ。`mu2000::rom_wave_pcm` で声と同じ読み方で取り出して試聴の道で鳴らすので、パートの設定は変わらない）、波形の全体とループの頭の拡大を出す。**ROM に波形の名前は無い**ので、名前の代わりに「その波形を使っている音色」（選ぶときの MSB・LSB・番号つき）と「使っているドラムの音」（キットと鍵。ドラムの打は波形の組を指さないので、波形 ROM の番地が同じことで結び付ける）を出し、使っている音色の**実機の液晶の楽器の絵**を添える（`src/xg/wave_catalog.h`）。名前・番号での絞り込み、「音色が使うもの / ドラムだけが使うもの / 使われていないもの」の切り替え、一覧を押してから上下の矢印キーで順に聞く、鍵の区切りごと（多段サンプル）の波形、`要素 N に使う`（音色のタブで編集している要素に入れて、そのタブへ移る）。音色のタブのサンプルの欄の `一覧…` からも開く。ドラムは XG のキット（バンク 127・126）と TG300B（GS）モードのキットを当たる。キットの番号は名前の表の番号とは別の並びなので、firmware でキットを 1 つずつ選んで読んだ値を使う（`voice_rom::kit_number`）。503 組のうち、音色が使うもの 435、ドラムだけが使うもの 59（W475 以降は Ntrl Kit・NtFunkKt の波形）、どの音色・どのキットからも使われていないもの 9（W175・196・205・216・217・223・229・456・465） |
| 内蔵音色 | **内蔵音色**のタブ。MU2000 の内蔵の音色（ROM の音色の記録 1635 個）を一覧にして、要素ごとに、どの内蔵ウェーブを・どの鍵と強さの範囲で・どんな音量・パン・音程・カットオフ / レゾナンス・音量 EG・LFO・遅れで鳴らしているかを表で出す（行 = 項目、列 = 要素 1〜4）。`鳴らす` のチェック（`全部` / `N だけ`）で要素を選び、**鍵 × 強さの図**（横 = 鍵、縦 = 強さ。各要素が鳴る範囲を色の枠で出す）の好きな所を押すと、その鍵と強さで**本物の音源で**鳴らす（押したまま動かすと鍵を渡っていく。強さで要素が切り替わる音色や、鍵で分かれている音色がひと目で分かる）。`押して試聴` と鍵・強さの欄でも鳴らせる。ROM の音色の要素とサンプル音色の要素は同じ 84 バイトの並びなので、音色の記録をサンプル音色の枠へそのまま写し（`mu2000::sampling_copy_preset`）、鳴らす要素の印だけを変えている（写したものは元の音色と同じ大きさで鳴る。samptest で 0.002 dB）。借りるのはサンプル音色のいちばん最後の枠（Bank# 1 の 128 番）とパート 1 で、枠の元の中身はタブを離れるか窓を閉じると戻す。波形の `W番号` を押すと内蔵ウェーブのタブでその波形を開き、内蔵ウェーブのタブの「使っている音色」の名前を押すとこちらでその音色を開く。`サンプル音色 Bank# b の n 番へ写す` で、音色を丸ごとサンプル音色にして編集できる（波形を自分のサンプルに差し替えるなど） |
| ライブラリ | **ライブラリ**のタブ。サンプリングのメモリは電源を切ると消えるので、作り込んだサンプル音色を 1 つずつ PC のファイルに取っておき、分類して、好きなものを選んで好きな枠へ戻す（`src/voice_lib.h`）。置き場は設定のフォルダーの `voices/`（その下のフォルダーが分類）、1 音色 = 1 ファイル（`.smuvoice`）。ファイルは音色の記録 350 バイトと、鳴らしているサンプルの波形・ループの設定・名前、覚え書きを持つ（内蔵ウェーブだけの音色は 400 バイトほど）。**保存**: 「音色」のタブで選んでいる枠を、名前・分類・覚え書きを付けて書く。**ロード（このエミュレーター）**: 選んだ枠へ戻す。要るサンプルは**番号でなく中身で**合わせ、同じもの（名前と波形が同じ）がメモリに無ければ空きへ足して、要素の指す番号を書き直す（`mu2000::sampling_import_voice`）。**ロード（実機の MU2000）**: その音色を書く SysEx（機種 0x68 のパラメータチェンジ 334 通）を MIDI OUT へ送る。実機の、その枠のサンプル音色だけを書く。**内蔵ウェーブだけの音色に限る**（サンプルの波形を実機のメモリへ書き足す道はまだ無い）。内蔵ウェーブだけの音色は、ロードせずに試聴できる（借りた枠で鳴らす）。名前・分類・覚え書きの書き直し、削除、名前や覚え書きでの絞り込み |

窓で足したサンプルも、パネルで録ったものと同じに扱われる（SAMPLE の画面に出る、試聴できる、続けてパネルで
録ればその後ろに入る、カードに保存できる）。A/D パートの音量は録るものに関係しない（A/D INPUT に入った値がそのまま録れる）。

## まだ書いていないもの

* `EDIT` の **`INST`** と **`KIT`**（複数のサンプルを鍵ごとに並べる・ドラムキットにする）。
  音色をいくつか作ってからでないと中身が確かめられないので、ここには書いていない
* `LOAD` / `SAVE` の `WAV`（PC で作った WAV を読み込む・書き出す）。カードへの出し入れは
  `tools/smcard.py` でできる（[gui.md](gui.md)）

## 手順を自分で確かめるには

パネルを文字だけで動かす道具に、押すたびに LCD を 1 行で出す `--trace` がある。

```bash
build/panel.exe <rom ディレクトリ> --keys "mode,left,left,left,enter" --trace
```

```
  mode       EDIT  LOAD  SAVE        |  REC   UTIL  RAM
  left       EDIT  LOAD  SAVE        |  REC   UTIL  RAM
  enter      SAMPLE   VOICE          |  INST     KIT
```

録音まで含めて確かめるには `build/samptest.exe <rom ディレクトリ> -v`（`make test` の 7 番）。
